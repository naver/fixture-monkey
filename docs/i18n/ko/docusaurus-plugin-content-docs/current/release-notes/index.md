# 릴리스 노트

메이저 버전별로 정리된 Fixture Monkey 릴리스 노트입니다. 각 페이지에는 유형별로 분류된 상세 변경 사항이 포함되어 있습니다.

## 최신: v1.2.0

- 새 adapter 엔진(`AssemblyPlanner` + `JvmTypeSystemPlugin`)이 기본 객체 생성 경로가 되었습니다
- 레거시 object tree 엔진과 실험적 `NodeTreeAdapter` SPI가 제거되었습니다

전체 변경 로그는 [v1.2.x](./v1.2.x)를 참조하세요.
