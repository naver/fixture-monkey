# Release Notes

Fixture Monkey release notes organized by major version. Each page contains detailed changelogs categorized by type.

## Latest: v1.2.0

- The new adapter engine (`AssemblyPlanner` + `JvmTypeSystemPlugin`) is now the default object generation path
- The legacy object tree engine and the experimental `NodeTreeAdapter` SPI have been removed

See [v1.2.x](./v1.2.x) for the full changelog.
